# Monetization

Display advertising is the intended primary revenue model, but usefulness and page depth come first. No network scripts or live ads are enabled.

The article rail contains a disabled, dimensioned `.ad-slot` as an integration seam. Future placements may include reserved in-content slots and a desktop rail. Enable only after the site has meaningful content, the privacy/consent framework matches the chosen vendors, and layout-shift tests pass. Avoid placing ads before the direct answer or creating layouts that fail when inventory is empty.

Record network and publisher IDs outside source control when secret. Document public IDs and exact injection points. Reassess sticky/anchor formats against mobile usability rather than enabling them by default.
