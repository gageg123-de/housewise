# SEO foundation

The root layout defines site-wide title behavior, metadata base, favicon, and the generated social card. The homepage alone emits WebSite and Organization schema; WebSite site-name markup is not repeated on every route, and the retired sitelinks SearchAction markup is not used. Independently shareable routes override title, description, Open Graph, and X metadata. Article routes use a registry-defined primary image for Open Graph, X, and Article schema when one exists; routes without a record-specific image explicitly clear the inherited site image.

Article pages emit Article and BreadcrumbList JSON-LD. Only category and symptom hubs with at least one published guide are generated, linked, indexed, and listed in the sitemap; empty taxonomy placeholders return the custom 404. Search and the custom 404 are `noindex,follow`, and the 404 has no canonical. `app/sitemap.ts` lists canonical indexable routes; `app/robots.ts` points crawlers to it. Do not add FAQ schema unless current search-engine rules and actual page content make it appropriate.

The artifact verifier treats rendered output as authoritative: indexable titles, descriptions, and canonicals must be unique; sitemap locations must exactly equal the rendered indexable canonical set; published articles must have inbound links and remain within four meaningful homepage clicks; and empty hubs, noindex utilities, stale hosts, obsolete SearchAction, and fabricated utility-route `lastmod` values fail validation.

Production canonical and structured-data URLs use `https://myhouseisdoingwhat.com/`. `site.config.json` is the deployment identity source; `lib/site-config.ts` composes root-based URLs without a repository prefix. The static sitemap uses the same configuration and is emitted at `dist/client/sitemap.xml`; robots points to `https://myhouseisdoingwhat.com/sitemap.xml` and disallows only `/search/`.

The GitHub Pages infrastructure URL must never appear as a canonical. GitHub redirects that URL after the custom domain is accepted, while production metadata consistently identifies the custom domain. After DNS and Pages configuration, verify every canonical/Open Graph/JSON-LD/sitemap URL and submit `https://myhouseisdoingwhat.com/sitemap.xml` in Search Console. Add the Google verification token to `metadata.verification.google` in `app/layout.tsx`.
